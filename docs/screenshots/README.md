# Screenshots Directory

This directory contains visual artifacts and screenshots of the Pelican web application for documentation and evaluation.

## Available Screenshots

| Filename | Description | Screen / State | Status |
|---|---|---|---|
| `pairing.png` | Session view with 6-character code, QR code modal, and "Waiting for the other device" status | `/session/:code` | Available |
| `transfer.png` | Active file transfer in progress showing file name, transfer speed (MB/s), percentage bar, and ETA | `/session/:code` | Available |
| `completed.png` | Finished transfer showing 100% completion status, elapsed duration, average speed, and SHA-256 hash preview | `/session/:code` | Available |
| `history.png` | Transfer history view showing sent and received records, search bar, status filter, and pagination | `/history` | Available |
| `devices.png` | Trusted devices dashboard showing registered machines/browsers, rename controls, and trust toggles | `/devices` | Available |
| `login.png` | User authentication screen with email and password input card | `/login` | Available |
| `registration.png` | User registration screen with name, email, and password input card | `/register` | Available |
| `dark-mode.png` | The interface rendered in dark theme mode demonstrating color palette and high contrast | Any screen in dark mode | Optional |

> Note: All images are PNG captures representing standard desktop or mobile viewports.
